# Windows Defender Manager (Direct Two-Binary Build)

Автономная утилита полного отключения и восстановления Windows Defender в Windows 10/11 без лишних интерфейсов и меню.

---

## 1. Содержимое и бинарники

В корне проекта и в папке `bin/` скомпилированы 2 чистых исполняемых файла:

- `disable.exe` — моментально и полностью отключает Windows Defender.
- `enable.exe` — восстанавливает Windows Defender и все его службы в штатное состояние.
- `build.bat` — скрипт быстрой компиляции обоих файлов (MSVC x64, статическая линковка `/MT`).

Никаких меню, баннеров и лишних диалогов.

---

## 2. Механизм отключения

1. Запуск от администратора автоматически задействует учетную запись `NT SERVICE\TrustedInstaller` через системный планировщик задач (`WinDefWorkerTask`).
2. Применяются реестровые ограничения:
   - Отключение AMSI, SmartScreen, Exploit Guard, WTDs, VBS, ETW логгеров.
   - Политики `DisableAntiSpyware`, `DisableRealtimeMonitoring`, заглушки IFEO и `DisallowRun`.
   - Остановка служб `WinDefend`, `SecurityHealthService`, `wscsvc`.
3. Soft-delete драйверов и ядра:
   - Драйверы (`WdFilter.sys`, `WdBoot.sys`) и бинарники ядра (`MsMpEng.exe` и др.) переименовываются в `.OLD`.
   - Защищенный манифест восстановления пишется в `%ProgramData%\WinDefState\manifest.dat`.
4. После перезагрузки ядро физически не может запуститься (файлы `.OLD`).

---

## 3. Механизм включения (Восстановление)

1. Запуск `enable.exe` от администратора.
2. Программа считывает `%ProgramData%\WinDefState\manifest.dat`, возвращает файлам исходные расширения и права учетной записи `TrustedInstaller`.
3. Очищаются политики блокировки и заглушки IFEO.
4. Службы переводятся в режим автозапуска.
5. После перезагрузки Defender возвращается в первоначальное состояние.

---

## 4. Как запускать

- **Отключить:** Отключить Tamper Protection в настройках Windows Security -> Запустить `disable.exe` от имени администратора -> Перезагрузить ПК.
- **Включить обратно:** Запустить `enable.exe` от имени администратора -> Перезагрузить ПК.
- **Тихий режим (без ожидания Enter):** запуск с флагом `-s` (например, `disable.exe -s` или `enable.exe -s`).
